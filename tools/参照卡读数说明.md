# P106 到手后的操作说明（★ 只读，零风险）

> 目的：拿到 P106 的参数，和 P104 做差分对比，找出"宽度声明"的配置点

---

## 一、准备工作（30 秒）

```
1. ★ 把 P104 从机器上拔下来（或者：如果两个槽都能插，两个都插上也行）
2. 把 P106 插到那条 x1 槽里
3. 接上 6-pin 供电
4. 开机，进 Windows
```

**★ 注意：P106 插在 x1 槽里【完全没问题】—— 只读参数，不测带宽。**

---

## 二、跑脚本（1 分钟）

```powershell
# 打开 PowerShell（管理员）

# 1. 先确认 P106 被识别
nvidia-smi

# 2. 跑只读脚本
cd D:\workplace2\dsh-workspace
.\.python312\python.exe tools\dump_card.py "tools\baselines\P106"
```

**★ 如果报"拿不到 session"（BYOVD 驱动没起来）：**

```powershell
# 禁用 Gen2 计划任务（P106 不需要它）
schtasks /change /tn "P104 PCIe Gen2x4 Bring-up" /disable

# 停掉 P104 的常驻进程
schtasks /end /tn "P104 PCIe Gen2x4 Bring-up"
Get-Process P104Gen2x4 -ErrorAction SilentlyContinue | Stop-Process

# 然后再跑脚本
```

---

## 三、输出结果

```
脚本会在 tools\baselines\ 下生成一个 P106_日期时间.txt
★ 输出即为该文件
```

---

## 四、★ 需要对比的内容

```
★★★ 第 1 优先：宽度声明
    P104: LNKCAP = 0x00454C42  →  MAXWIDTH = 4
    P106: ?
       = 16  ⇒ ★★★ 声明确实可配置 ⇒ 全力找配置点 ⇒ P104 有救
       = 4   ⇒ 说法需要重新核实

★★★ 第 2 优先：PUNITS 页那 5 个未文档化的值
    P104: 0x022450=2  0x022454=8  0x022458=1  0x02245C=2  0x022460=3
    P106: ?
      ★ 如果不一样 ⇒ 它们就是 SKU 配置 ⇒ 可能藏着宽度/引擎信息

★★ 第 3 优先：PFUSE 页整页差分
    P104 的 TPC_DISABLE_MASK = 1（熔丝关 1 个 TPC）
    P106: ?（GP106 是不同芯片，会有一堆正常差异，要挑着看）

★ 第 4 优先：速率声明
    P104: MAXSPD=Gen2, LNKCAP2=0x06
    P106: ?（如果 P106 声明 Gen3，那就又一条线索）
```
