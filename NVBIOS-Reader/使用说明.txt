========================================================
   NVIDIA VBIOS 读取器   NVBIOSReader v1.2
========================================================


【这是干什么的】

  一个只读小工具：把 NVIDIA 显卡里的 VBIOS（显卡的固件）读出来，
  存成一个 .rom 文件，或者跟已有文件比对是否一致。

  为什么需要它：
    · 有些矿卡（P104-100 / P106-100 / CMP 系列）用 GPU-Z 存不了 VBIOS
    · 用编程器（CH341A）要拆机接线，麻烦又危险
    · nvflash 在部分机器上会导致重启

  ★★★ 本工具【全程只读】—— 它只"看"显卡，不会写入、不会刷写、
        不会改任何设置。用完显卡跟用之前一模一样。


【三步就能用】

  第 1 步：解压
     把压缩包解压到任意目录（路径里有中文、有空格都不影响）。

  第 2 步：双击  NVBIOSReader.exe
     · 会弹出"是否允许此应用对你的设备进行更改" → 点【是】。
       （读显卡必须要管理员权限；本工具已自带申请，不用你去右键。）
     · 窗口打开后会自动扫描，几秒后在列表里显示你的显卡。

  第 3 步：在列表里选中你的显卡，然后
     · 只想看 VBIOS 的 MD5  → 点【读取（只看）】
     · 想存成文件           → 点【读取并保存】，再选一个保存位置


  小提示：
    · 列表里每一行就是一张 NVIDIA 显卡。如果插了多张（例如矿卡＋主卡），
      选你要读的那一张。
    · 想一次全存下来 → 点【保存全部】。


【文件说明】

  NVBIOSReader.exe          ← ★ 双击这个就行（图形界面版）
  使用说明.txt              ← 本文件
  bin\NVBIOSReader-CLI.exe  ← 命令行版（进阶用法见后面）
  bin\drivers\              ← ★ 必需的两个驱动，不要删、不要移走
      WinRing0x64.sys           读 PCI 配置空间
      ThrottleStop.sys          映射显卡的内存
  src\                      ← 源码。普通使用完全用不到，可以不管。


【常见问题】

  Q1. 双击后弹出"是否允许此应用对你的设备进行更改"
      → 点【是】。这是 Windows 在要管理员权限，读显卡必须有。
        如果点了【否】，窗口会提示"需要管理员权限"并退出。

  Q2. 提示"没有管理员权限"
      → 关掉窗口，右键 NVBIOSReader.exe → 以管理员身份运行。

  Q3. 提示"底层驱动不可用" / "驱动装载失败"
      ① ★ 最常见：同时开着别的用 WinRing0 的同类工具
         （例如 P104-Gen2x4 这类工具）。两个工具用的是【同一个】底层驱动设备，
         同时用会互相干扰，表现就是"连不上"、"读不到设备"。
         → 请把其它同类工具关掉，再重新打开本工具。
      ② 杀毒软件把 bin\drivers\ 里的两个驱动拦截了 → 把整个目录加白名单。
      ③ 之前有程序被"强制结束"过，驱动卡在坏状态 → 重启电脑后再试。

  Q4. 提示"易受攻击驱动程序阻止列表"
      → Windows 11 会拦 WinRing0。解决办法：
        Windows 安全中心 → 设备安全性 → 内核隔离 →
        关闭"Microsoft 易受攻击驱动程序阻止列表" → 重启电脑。

  Q5. 提示"未找到 NVIDIA 显示设备"
      → 确认是 NVIDIA 显卡，且设备管理器里没有黄色感叹号。

  Q6. 读出来的 MD5 跟 GPU-Z 的不一样
      → GPU-Z 保存时可能补 0 到 512KB。本工具读的是显卡 ROM 映射里的
        原始 256KB。以本工具的为准。

  Q7. 双击没反应 / 窗口一闪就没了
      → 看 exe 同目录有没有「启动错误.log」，打开它会写明原因。

  Q8. 怎么确认"它真的没改我的显卡"？
      → 读两次：读之前记下 MD5，读之后再读一次，两次一样；
        而且本工具代码里对显卡只有"读"操作，没有任何写入调用。


【进阶：命令行版（一般用不到）】

  打开"命令提示符"，cd 到本目录，然后：

    bin\NVBIOSReader-CLI.exe                   扫描所有卡，打印 MD5 / SHA256
    bin\NVBIOSReader-CLI.exe -save D:\bak      存到指定目录
                                               （不给目录就存到 exe 同目录的 VBIOS备份\）
    bin\NVBIOSReader-CLI.exe -verify x.rom     把卡上的 VBIOS 与 x.rom 比对

  （命令行版同样会自动申请管理员权限。）


【★ 一个实用场景：刷写前后校验】

  刷 VBIOS 之前：先读一次存成 backup.rom
                  （这一步同时确认了"卡上现在是原厂内容"）
  刷 VBIOS 之后：立刻再读一次，跟 backup.rom 比 MD5
       变了  → 说明写进去了  ✔
       没变  → 说明没刷上    ✘（此时【先别重启】，先排查）

  ⇒ 把"盲赌"变成"可验证"，避免刷坏了还不知道。
