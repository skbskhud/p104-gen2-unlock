⚠ 与其它同底层工具的冲突
------------------------------------------------------------------------------
  本工具使用 WinRing0 底层驱动访问 PCI 配置空间，而该驱动的设备名是
  【全系统唯一】的（\\.\WinRing0_1_2_0）。若同时运行其它基于 WinRing0 的工具
  （各类显卡/主板寄存器读取、VBIOS 提取工具等），可能出现

      "连不上设备 / 打不开驱动 / 读不到寄存器"

  这类报错。遇到时请【先关闭其它同类工具】，再重试本工具。



  看不懂 md 文件的朋友，看这一份就够了。
  本文件用记事本打开即可，不需要任何特殊软件。


--------------------------------------------------------------------------------
【成果是什么】
--------------------------------------------------------------------------------

  把 P104-100 显卡的 PCIe 速度从 Gen1（2.5GT/s）提到 Gen2（5.0GT/s）。

  实测带宽：
      解锁前   H2D 0.78 GB/s    D2H 0.85 GB/s
      解锁后   H2D 1.55 GB/s    D2H 1.69 GB/s
      提升     约 2 倍

  全程纯软件，不刷显卡固件，不改硬件，可以完全还原。


--------------------------------------------------------------------------------
【★ 重要：杀毒软件报警是正常的，先看这段】
--------------------------------------------------------------------------------

  解压后 Windows 安全中心可能会报警，说是"有害"或"HackTool / 风险软件"。

  这是【预期行为】，原因如下：

  本工具需要直接读显卡内部寄存器，这在 Windows 应用层做不到，
  必须借助两个内核驱动：
      WinRing0x64.sys
      ThrottleStop.sys

  这两个驱动是公开的、有正规数字签名的驱动（社区通用工具），
  但这类驱动（安全界叫 BYOVD）也能被坏人利用，所以杀毒软件一律标记它们。

  重要：本工具的所有代码都在 src\P104Gen2x4.cs 里，是纯文本，
        你可以自己打开看，或者找懂编程的朋友帮你审。没有任何隐藏行为。

  ─── 怎么处理 ───

  如果只是解压报警：允许 / 忽略即可，不影响使用。

  如果运行时提示"驱动加载失败：错误 1275"，说明系统的
  「易受攻击的驱动程序阻止列表」开着，需要关掉它：

      1. 打开 Windows 安全中心
      2. 点「设备安全性」
      3. 点「内核隔离」
      4. 找到「Microsoft 易受攻击的驱动程序阻止列表」，关掉
      5. 【重启电脑】   ← 必须重启才生效
      6. 重新运行 install.cmd

  如果提示"错误 31"，说明被反作弊的预启动驱动拦了
  （最常见是腾讯游戏的 ACE-BOOT）。这种情况需要先停掉它，
  或者换一台没有反作弊软件的电脑来弄。

【使用前的准备】
--------------------------------------------------------------------------------

  1. 系统：Windows 10 或 Windows 11（64 位）
  2. 显卡：NVIDIA P104-100
  3. 权限：必须是【管理员】
  4. 先做上面那段"杀毒软件"的处理

  怎么确认是管理员？
      右键 install.cmd，菜单里如果有「以管理员身份运行」，就选它。
      如果运行后提示"需要管理员权限"，就是没选对。


--------------------------------------------------------------------------------
【使用方法：三步】
--------------------------------------------------------------------------------

  第 1 步   解压

      把 P104-Gen2x4-组合包-v1.0.zip 解压到一个文件夹，
      比如 D:\P104-Gen2x4

      【注意】要先完整解压，不要直接在 zip 里双击运行。


  第 2 步   安装

      在这个文件夹里找到  install.cmd
      右键它 → 选「以管理员身份运行」
      等它跑完（会显示一堆文字，最后停在"安装完成"）
      按任意键关闭窗口

      它做四件事：
        · 把文件复制到 C:\Program Files\P104Gen2x4\
        · 写入三条显卡驱动策略
        · 注册一个开机自动运行的任务
        · 立刻解锁一次


  第 3 步   重启电脑（建议）

      重启后约 2-4 分钟会自动解锁（冷启动需要时间，期间请耐心等待，不要手动反复运行工具），以后不用再管。


--------------------------------------------------------------------------------
【怎么确认成功了】
--------------------------------------------------------------------------------

  方法一（推荐）：双击文件夹里的  status.cmd
      【注意】这个不需要"以管理员身份运行"，直接双击就行。
      它会告诉你一句话结论，比如：
          "结论：【正常】Gen2 已解锁，且正在保持"
      看到这句就成了。

      如果它显示"按住进程未运行"，说明守护进程没跑，
      双击 C:\Program Files\P104Gen2x4\P104Gen2x4.exe 即可。

      想看寄存器的原始数字（排查问题时才需要），
      就右键 status.cmd 选"以管理员身份运行"。

      看输出里这一行：
          LNKSTA=0x00001042(5.0GT/s x4)
                     ^^^^^^^^^^^^^^^^
                     这里显示 5.0GT/s x4  就是成功

      如果显示 2.5GT/s x4，说明没成功，看下面"出问题怎么办"。


  方法二：双击 bin\check-bw.cmd（★ 最可信，推荐）

      它会实测一次真实带宽，并直接给出判定：

          H2D (主机→显卡) : 1.5622 GB/s
          ★ 判定：Gen2 x4   （★ 目标达成）

      参考值（x4 宽度）：
          Gen1 x4 = 约 0.78 GB/s
          Gen2 x4 = 约 1.55 GB/s    <- 目标
          Gen3 x4 = 约 3.10 GB/s

      为什么推荐这个：带宽是唯一不会骗人的判据。


  方法三：打开 GPU-Z（★ 但别用它当判据，看下面的说明）

      GPU-Z 的「Bus Interface」那一栏会显示成这样：

          PCIe x4 2.0 @ x4 1.1
          ^^^^^^^^^^^   ^^^^^^
          能力声明       当前速率
          (最高能跑)     (实际在跑)

      ★ 这台机器上，后面的"当前速率"【始终显示 1.1】，即使链路真的是 2.0。
        原因是 GPU-Z 读的是 NVIDIA 驱动上报的值，在无显示输出的矿卡上不可靠。

      ★ 所以：GPU-Z 显示 "1.1" 不代表没解锁成功。
        要以 bin\check-bw.cmd 的带宽实测、或 status.cmd 里的 LNKSTA 原始值为准。


  方法四：看有没有东西在后台运行

      按 Ctrl+Shift+Esc 打开任务管理器
      在"详细信息"里找  P104Gen2x4.exe
      有它 = 正常      没有 = 链路会掉回 Gen1


--------------------------------------------------------------------------------
【★★★ 一个特别容易搞错的地方：GPU-Z 显示 Gen1 是正常的】
--------------------------------------------------------------------------------

  这里有两种完全不同的情况，别混在一起：

  情况 A：显卡空闲时显示 Gen1，有负载时回到 Gen2
          ⇒ 这是省电降速，正常现象。

  情况 B：有负载时也一直显示 Gen1，但 status.cmd 说 Gen2
          ⇒ ★ 这不是故障 —— 是 GPU-Z / nvidia-smi 读错了。
            它们读的是【NVIDIA 驱动上报的值】，不是 PCIe 寄存器。
            在这张无显示输出的矿卡上，这个值不可靠：
              寄存器 LNKSTA 说 5.0GT/s，带宽实测 1.56 GB/s（都是 Gen2）
              但 nvidia-smi 的 pcie.link.gen.current 始终报 1。

  ★ 怎么分辨是哪种：双击 bin\check-bw.cmd
       带宽 ≈ 1.55 GB/s  ⇒  链路真的是 Gen2（情况 B，没事）
       带宽 ≈ 0.78 GB/s  ⇒  链路真的掉回 Gen1 了（需要排查）


--------------------------------------------------------------------------------
【★ 哪些字段能当判据，哪些绝对不能】
--------------------------------------------------------------------------------

  能当"当前速率"判据的（按可信度排序）：

      1. 带宽实测（bin\check-bw.cmd）              ← 最可信
      2. LNKSTA 的 SPD[3:0]（status.cmd 会打印）
            = 2 ⇒ 5.0GT/s (Gen2)
            = 1 ⇒ 2.5GT/s (Gen1)

  绝对【不能】当"当前速率"判据的：

      LNKCAP[3:0]        = 能力上限（"我最高能跑多少"）
      LNKCAP2[6:1]       = 支持速率向量（"我支持哪几代"）
      LNKCTL2[3:0] (TLS) = 目标速率请求（"我希望跑多少"）
      nvidia-smi 的 pcie.link.gen.*  = 驱动缓存值，本卡不可靠
      GPU-Z 的 Bus Interface 后半段   = 同上

  ★ 历史教训：本项目的开发者曾因为拿 LNKCAP2 当判据，
    三次误报"Gen3 成功"。所以这条写得很重。

  所以看到一个 Gen1 不代表失败！

  ★ 那到底看什么？—— 看这两样，别的一律不看：

      1. bin\check-bw.cmd 的带宽实测
           约 1.55 GB/s  ⇒  真的 Gen2 x4

      2. status.cmd 里的 LNKSTA 原始值
           SPD[3:0] = 2  ⇒  5.0GT/s (Gen2)

  ⚠️ 特别注意：不要把 LNKCTL2 的 TLS 当"当前速率"用。
     TLS 是【目标速率请求】（"我希望跑多少"），不是【当前在跑多少】。
     同理，LNKCAP 是能力上限，LNKCAP2 是支持速率向量 —— 都不是当前速率。

  同样，nvidia-smi 和 GPU-Z 显示的 PCIe 速度也是不准的，
  它们读的是 NVIDIA 驱动上报的值，在这张矿卡上永远显示 Gen1，不用管它。

【出问题怎么办】
--------------------------------------------------------------------------------

  ─── 情况 1：提示"驱动加载失败：错误 1275" ───
      系统的易受攻击驱动阻止列表开着。
      按本文档上面"怎么处理"那一节，关掉它并重启。

  ─── 情况 2：提示"驱动加载失败：错误 31" ───
      被反作弊的预启动驱动拦了。
      临时停掉它，或者换一台没有反作弊软件的电脑。

  ─── 情况 3：跑完 status.cmd 还是显示 2.5GT/s x4 ───
      按顺序检查：
        (1) 任务管理器里有没有 P104Gen2x4.exe
            没有 → 双击 C:\Program Files\P104Gen2x4\P104Gen2x4.exe
        (2) 计划任务在不在
            打开"任务计划程序"，找 P104 PCIe Gen2x4 Bring-up
            没有 → 重新运行 install.cmd
        (3) 看日志
            打开 C:\ProgramData\P104Gen2x4\status.txt
            拉到最下面，看报什么错

  ─── 情况 4：显卡从设备管理器里消失了 ───
      极少数主板会出现这种情况。
      【重启电脑】就好，不会损坏显卡。
      重启后显卡会回来，只是速度还是 Gen1。

  ─── 情况 5：本来好了，过一会儿又变回 Gen1 ───
      按住进程被结束了（可能被杀毒软件杀了）。
      处理：
        (1) 把 C:\Program Files\P104Gen2x4\ 加入杀毒软件白名单
        (2) 重新运行 install.cmd
        (3) 或者直接双击 C:\Program Files\P104Gen2x4\P104Gen2x4.exe

  ─── 情况 6：不想用了，想彻底恢复原状 ───
      右键 bin\uninstall.cmd → 以管理员身份运行 → 重启电脑
      会把所有东西删掉，显卡回到出厂状态。


--------------------------------------------------------------------------------
【重要提醒】
--------------------------------------------------------------------------------

  · 玩带反作弊的游戏之前，建议先运行 bin\uninstall.cmd 卸载，然后重启。
    因为本工具用的内核驱动会被反作弊软件针对。

  · 本工具只操作 P104-100 这一张卡（设备 ID 10DE:1B87），
    不影响你机器上的其他显卡。

  · 如果这台电脑的显卡就是负责显示的，禁用/启用它的时候屏幕会黑一下。
    P104-100 没有显示输出接口，所以不会有这个问题。


--------------------------------------------------------------------------------
【卸载方法】
--------------------------------------------------------------------------------

  右键 bin\uninstall.cmd → 选「以管理员身份运行」
  跑完后重启电脑即可完全恢复。
