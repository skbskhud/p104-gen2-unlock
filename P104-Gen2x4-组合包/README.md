## 一、这是什么

一张 P104-100 矿卡，插在正常主板上，PCIe 链路会被初始化成 **Gen1（2.5GT/s）**，
而它的核心 GP104 和 GTX 1070 是同一颗芯片。这导致 CPU↔显存的数据搬运速度
只有它应有水平的一半。

社区长期认为这是**硬件限制**（"矿卡低分档""PCB 限制""只能 Gen1"），
国内外的 P104/P106 魔改圈也没有公开的 Gen2/Gen3 成功记录。

**本工具证明那个结论是错的**，并给出了可复现的完整方法。

## ⚠️ 杀毒软件会报警 —— 这是预期行为，请先看这一节

### 现象

解压后会弹 Windows 安全中心告警，标记为 **HackTool / Hacktool:Win64/WinRing0**
或 **RiskWare**；有的杀软会直接删掉里面的 `.sys` 文件或整个 zip。

### 原因

本工具需要直接读写 GPU 的 BAR0 寄存器与 PCI 配置空间，这在 Windows 应用层做不到，
必须借助两个内核驱动：

```
bin\drivers\WinRing0x64.sys
bin\drivers\ThrottleStop.sys
```

这两个是**公开的、带有效数字签名的**驱动（社区通用工具，40HX / P106 等解锁项目都在用），
但这类驱动（安全界称 **BYOVD**，Bring Your Own Vulnerable Driver）**可以被人利用来做坏事**，
所以杀毒软件一律标记它们，不管用在哪、用得多正当。

**同一个原因有两种表现**：
- 下载/解压阶段 → 杀软报警
- 运行阶段 → 驱动加载失败（**错误 1275** 或 **错误 31**）

### 本工具到底做了什么

**全部代码都在 `src\P104Gen2x4.cs`，是纯文本，可逐行审阅。** 它只做四件事：

1. 用那两个驱动读写 P104 的寄存器与配置空间（只针对 `10DE:1B87` 这一个设备）
2. 通过 SetupAPI 把 P104 **禁用一次、再启用一次**
3. 往显卡类键写三条注册表策略（`RMPcieLinkSpeed` 等）
4. 注册一个开机自启的计划任务

**不联网、不写 Flash/EEPROM、不碰其他设备、除了按住进程之外不驻留任何东西。**

### 怎么处理

| 情况 | 处理 |
|---|---|
| 只是解压/下载报警 | 允许 / 保留文件 即可，不影响使用 |
| 文件被删了 | 关闭杀软实时防护（或把解压目录加白名单），重新解压 |
| 运行报 **错误 1275** | 关「易受攻击的驱动程序阻止列表」→ **重启** → 重跑 `install.cmd` |
| 运行报 **错误 31** | 被反作弊预启动驱动拦截（常见：腾讯 `ACE-BOOT`）。停掉它，或换台机器 |

**关闭"易受攻击的驱动程序阻止列表"的步骤**：

```
Windows 安全中心 → 设备安全性 → 内核隔离
  → 找到「Microsoft 易受攻击的驱动程序阻止列表」→ 关闭
  → 【重启电脑】（必须重启才生效）
```

> 💡 用完想恢复：把那个开关重新打开即可；或者运行 `bin\uninstall.cmd` 卸载本工具。

### 如果你不放心

## 三、实测数据

| 项目 | 解锁前 | **解锁后** | 提升 |
|---|---|---|---|
| 链路速率 | 2.5 GT/s (Gen1) | **5.0 GT/s (Gen2)** | 2× |
| 链路宽度 | x4 | x4 | — |
| **H2D 单向** | 0.780 GB/s | **1.553 GB/s** | **1.99×** |
| **D2H 单向** | 0.851 GB/s | **1.693 GB/s** | **1.99×** |

稳定性验证（40 秒满负载、61 轮 512MB 双向搬运）：

```
H2D  平均 1.548 GB/s（最低 1.502 / 最高 1.554）
D2H  平均 1.692 GB/s（最低 1.691 / 最高 1.693）
链路监控 2043/2043 次采样 = Gen2，从未掉回 Gen1
```

寄存器证据：

```
LNKCAP  = 0x00463C42   → 上限 5.0GT/s(Gen2) x4
LNKCAP2 = 0x00000006   → 支持速率向量 = 3（Gen1 + Gen2）  ← 声明解锁
LNKSTA  = 0x00001042   → 当前 5.0GT/s(Gen2) x4            ← 链路达成
LNKCTL2 = 0x00000002   → 目标速率 TLS = 2
```

## 四、★★ 核心原理（一句话版）

> **P104 的限制不是"硬件锁死"，而是它开机时向系统"声明"自己只支持 2.5GT/s。
> 只有一次【真正的整卡复位】——把设备从总线上摘下来再装回去——才能让它的
> PCIe 核重新锁存声明为 Gen2。声明一变，正常的两端重训就能把链路拉到 Gen2 x4。**

**这就是全部秘密。** 详细的推导过程、走过的所有弯路、以及"为什么别人失败"

### `-status` 和 `-diag` 的区别

| | `-status` | `-diag` |
|---|---|---|
| 需要管理员 | **不需要** | 需要 |
| 数据来源 | 工具自己的运行日志 | 直接读 GPU 寄存器 |
| 会不会干扰按住进程 | **不会** | 会短暂加载驱动 |
| 输出 | 一句话结论 | 寄存器原始值 |
| 用途 | **日常看"成了没"** | 排查问题、收集诊断数据 |

> 所以 `status.cmd` 走的是不需要管理员的那条路。

## 八、风险与免责

**本工具做了什么**：
- 用两个已知的 BYOVD 类内核驱动（`WinRing0x64.sys`、`ThrottleStop.sys`）
  读写 GPU 的 BAR0 寄存器与 PCI 配置空间
- 通过 SetupAPI 对 P104 **禁用一次再启用一次**（会造成 5~10 秒链路瞬断）
- 写三条 NVIDIA 驱动注册表策略到显卡类键
- 注册一个开机自启的计划任务

**风险提示**：
- 需要加载未签名的 BYOVD 内核驱动 → 属于降级系统防护
- 禁用/启用设备期间，如果这张卡是显示卡，屏幕会黑一下（**P104 没有显示输出，不受影响**）
- 极少数主板在这种复位下会让卡掉线，**重启即可恢复，不会造成物理损坏**
- 玩带反作弊的游戏前，建议先 `bin\uninstall.cmd` 并重启

**免责**：本项目仅用于自己拥有的硬件的合法研究。使用风险自负。

## ★ 新增功能：VBIOS 读取与校验（`-vbios`）

### 这是什么

本工具能**直接读取卡上的 VBIOS**（通过 BAR0 的 ROM 映射窗口），
**不需要 nvflash，不会重启机器，零风险**。

### 用法

```
bin\P104Gen2x4.exe -vbios              只读并算哈希
bin\P104Gen2x4.exe -vbios -save a.rom  同时把 ROM 存成文件
bin\vbios.cmd                              便捷脚本（双击即可，需要管理员）
```

### 输出示例

```
ROM 头: 0xEB79AA55 0x3034374B 0x194CE930
ROM 摘要 : ...IBM VGA Compatible......HT02/24/19
ROM 大小 : 262144 字节 (256 KB)
★ MD5    : 24342b9b2b09bebb52059a6d15ce36f1
★ SHA256 : 1de5cde3dc351164a813ca31ad71920f77c149078f83bfd3009969736b10e684
```

### 为什么有用

| 场景 | 怎么用 |
|---|---|
| **刷写前** | 算备份 ROM 的 MD5（`certutil -hashfile <备份.rom> MD5`），与本工具的输出对比。一致说明卡上是原厂内容 |
| **刷写后** | 再跑一次。MD5 变了 = 写进去了；还是旧的 = 刷新没生效（**此时先别重启，先排查**） |
| **日常检查** | 任何时候都能确认 EEPROM 内容有没有意外变化 |

### 原理（实测发现）

本卡的 VBIOS ROM 完整映射在 **BAR0 + 0x300000**（256KB，只读），
并且还有一个完全相同的第二镜像在 **BAR0 + 0x380000**。

实测：逐字节与原厂 dump 对比 **100% 匹配**，MD5/SHA256 完全一致。

> ⚠️ 这个窗口是**只读**的 —— 能读不能写。所以刷写本身仍需 nvflash，
> 但**刷写前后的校验现在可以自己做**，风险显著降低。
