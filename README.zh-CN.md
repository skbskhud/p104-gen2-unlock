# P104-100 PCIe Gen2 x4 解锁工具

**[English](README.md)** | 中文

> 一个 Windows 小工具：把 NVIDIA **P104-100**（GP104 矿卡）的 PCIe 链路从 **Gen1 x4**
> 提到 **Gen2 x4**，实测单向带宽大约翻倍。
>
> 同一张卡、同一个插槽实测：**0.78 → 1.55 GB/s**（主机 → 显存），
> **0.84 → 1.69 GB/s**（显存 → 主机）。

---

## 这个工具做什么

```
改前：PCIe Gen1 x4  ≈ 0.78 GB/s（出厂状态）
改后：PCIe Gen2 x4  ≈ 1.55 GB/s（本工具）
```

工具让端点重新协商到 Gen2，同时保持 x4 宽度。改动**随时可以恢复**（`uninstall.cmd`），
不写 VBIOS、不写 EEPROM。

---

## 实测数据

| 链路状态 | 主机 → 显存 | 显存 → 主机 |
|---|---|---|
| Gen1 x1 | 0.197 GB/s | 0.209 GB/s |
| Gen2 x1 | 0.390 GB/s | 0.420 GB/s |
| **Gen1 x4（出厂）** | **0.778 GB/s** | **0.835 GB/s** |
| **Gen2 x4（本工具）** | **1.55 GB/s** | **1.69 GB/s** |

寄存器指纹（同卡同槽）：

```
               Gen1 状态      Gen2 状态
LNKSTA         0x00001041     0x00001042   ← 当前链路速度
LNKCAP2        0x00000002     0x00000006   ← 端点声明的速度
LNKCAP         0x00463C41     0x00454C42   ← 最大速度/宽度声明
LINK_CONFIG_0  0x20585800     0x20545800
PL_LINK_RATE   0x00110036     0x00120036
```

## 环境要求

```
显卡    NVIDIA P104-100（10DE:1B87）
系统    Windows 10 / 11 x64
权限    管理员
```

测试平台：P104-100 位于 `01:00.0`，上游 `00:01.0`（声明 Gen4 x16），
Intel i9-14900KS，Windows 11 x64。

换主板、换插槽、换卡批次都可能不同 —— 用之前和之后都测一遍。

## 快速开始

```bat
:: 1) 安装（包含一次设备复位和短暂等待）
install.cmd

:: 2) 查看当前链路状态和带宽（不需要管理员）
status.cmd
check-bw.cmd

:: 3) 恢复出厂状态
uninstall.cmd
```

`status.cmd` 会打印 `LNKSTA`（当前速度）、`LNKCAP2`（声明的速度）和实测带宽。
**判断依据是 `LNKSTA` 和带宽数字**，不是能力声明。

成功后的输出大致是：

```
LNKSTA      0x00001042
Bandwidth   ~1.5 GB/s  （主机 -> 显存）
```

## 注意事项

- 工具需要两个内核驱动来访问 PCIe 配置寄存器。
  **杀毒软件和反作弊会报警 —— 这是正常现象。**
  使用时加白名单或暂时关闭保护，用完再恢复。
- 工具改的都是临时寄存器状态。重启也会恢复出厂链路，所以 `uninstall.cmd` 是为了方便，
  不是非用不可。
- 不要在显卡正接显示器、且你正需要画面的情况下运行 —— 第 1 步的设备复位会让屏幕黑一下。
- 只用于你自己的硬件。
